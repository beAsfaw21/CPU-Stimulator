## [1.0.0] - 2026-10-30

### Added

- MIT license
- Java and generated-file ignore rules
- GitHub Actions workflow for compilation and tests
- Contribution guidelines
- GitHub issue and pull request templates
- GitHub issue configuration and private security reporting link
- GitHub CODEOWNERS configuration
- Sample assembly programs
- Beginner-friendly project documentation
- Additional assembler and CPU tests
- Correct `CALL` and `RET` subroutine execution
- Detailed instruction-set reference
- Beginner-focused assembly language guide
- Contributor-focused development guide
- Documentation index
- Sample-program guide with expected results and learning order
- Testing guide with test-writing and CI instructions
- README badges for CI status and license
- Project roadmap for future improvements
- Expanded conditional-branch test coverage
- Added nested subroutine and return-address tests
- Explicit memory-address validation and boundary tests
- Clearer GUI errors for file, assembly, execution, and step-limit failures
- GUI reset control for restarting execution without reopening source files
- Configurable maximum execution-step limit in the GUI
- In-app instruction reference for assembly mnemonics and operands
- Source-line breakpoint control in the GUI
- Register and ALU flag change indicators in the GUI
- Makefile with common build, test, run, and clean commands
- EditorConfig formatting rules
- Support and question-reporting guidance
