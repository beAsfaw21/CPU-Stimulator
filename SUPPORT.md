# Support

## Before asking for help

Please check the following resources first:

- [README.md](README.md) for installation and usage
- [Assembly language guide](docs/assembly-guide.md) for programming examples
- [Instruction set reference](docs/instruction-set.md) for supported operations
- [Architecture guide](docs/architecture.md) for CPU behavior
- [Troubleshooting](README.md#troubleshooting) for common problems

## Where to ask questions

For general questions about using or learning from the simulator, open a GitHub issue with the `question` label when available. Include:

- What you were trying to do
- The command or assembly source involved
- What you expected to happen
- What happened instead
- Your operating system and Java version

Use a small, reproducible example whenever possible.

## Reporting bugs

Use the [bug report template](.github/ISSUE_TEMPLATE/bug_report.md). Include the smallest assembly program or set of steps that reproduces the problem.

## Requesting features

Use the [feature request template](.github/ISSUE_TEMPLATE/feature_request.md). Explain the problem the feature would solve and provide an example of the proposed behavior.

## Security issues

Do not report security vulnerabilities in public issues. Follow the private reporting instructions in [SECURITY.md](SECURITY.md).

## Contributing fixes

If you can fix the problem, review [CONTRIBUTING.md](CONTRIBUTING.md) and [docs/development-guide.md](docs/development-guide.md) before opening a pull request.
