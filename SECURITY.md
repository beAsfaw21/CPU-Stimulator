# Security Policy

## Supported versions

The project currently supports the latest repository state on the default branch. Security updates are applied to the current mainline development code.

## Reporting a vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Instead, report the issue privately to the maintainers by emailing the repository owner or using the project's private contact information listed on the GitHub profile.

When reporting a vulnerability, include:

- A description of the issue
- The affected file or component
- The version or commit hash
- Steps to reproduce the vulnerability
- Any proof of concept or exploit details
- Your preferred contact information

## What to expect

After a report is received, the maintainers will:

- Acknowledge receipt within a reasonable timeframe
- Assess the report and determine severity
- Work on a fix or mitigation
- Coordinate a safe disclosure timeline when appropriate

## Responsible disclosure

Please avoid sharing details publicly until the maintainers have had a chance to investigate and remediate the issue.

We appreciate responsible disclosure and will do our best to address legitimate security issues promptly.
